# Сценарій демо · City Insight Map · Енергія

Відео **≤ 3 хв**, щонайменше 2 сценарії треку. Цей самий маршрут — для живого демо на пітчі.

- Сайт: **https://pl.mindal1ka.com**
- Вхід **тестовий**: ПІБ (наприклад, «Демо Енергоменеджер»), посада — необов'язково (можна обрати підказку), будь-який пароль. Справжні ПІБ не вводимо.
- Перемикач **«Зараз / Літній день»** угорі сторінок: «Літній день» = **05.06.2026, 13:00** (`?view=summer`). Узимку станції в дефіциті, влітку видно надлишок.
- Усе, що позначено **«ДЕМО»**, — змодельовані станції, акумулятори й телеметрія. Кажемо це вголос один раз (00:20). Про реальні заклади ніколи не кажемо «не має резервного живлення» — лише «у системі резерв не зафіксовано (ДЕМО)».
- Пошук будь-якої будівлі — **Ctrl+K**. Кнопка «?» угорі — тур «Як користуватися» (у демо не показуємо, але згадати можна).

**Перед записом:** увійти заздалегідь (вхід живе у вкладці), відкрити вкладки нижче, масштаб браузера 110–125 %, сповіщення вимкнути. Тур «Як користуватися» на першому візиті закрити заздалегідь.

## Якщо мережа впала

1. **Локальна копія** (запустити заздалегідь, до 14:00): `docker compose up --build` у корені репозиторію → http://localhost:8000. Ті самі шляхи: `/`, `/?view=summer`, `/map`, `/object/9623?view=summer`, `/independence`, `/solar?budget=5`, `/solar/9602`, `/defects`. PVGIS у кеші, тож мережа не потрібна. Прогноз Open-Meteo без мережі показує середнє PVGIS з позначкою. **Підкладка мапи (тайли OpenStreetMap) без мережі не завантажиться** — точки будуть, карти під ними ні; тоді мапу пропускаємо.
2. **Відео** на ноутбуці й на флешці (MP4) — запустити замість живого демо.
3. **Скріншоти** ключових екранів у PDF слайдів (слайд 8) — останній варіант.
