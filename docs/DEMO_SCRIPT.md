# Сценарій демо · Insight Tool — енергоменеджмент Полтавської громади

Відео **≤ 3 хв**, на реальному прототипі, **два сценарії** (+ необов'язковий третій):
1. **Енергоменеджер** (логін `energo`): ефективність СЕС і що добудувати (кейс 2.2);
2. **Фінансове управління** (логін `finance`): бюджет, ліміти, звіт за місяць (кейс 2.3, Ф2.3-07);
3. *(необов'язково)* **Готовність до блекауту** — лише з позначкою «ДЕМО».

- Сайт: **https://pl.mindal1ka.com** (або локально http://localhost:8000). Без входу застосунок нічого не показує — гостьового режиму немає.
- Вхід: логін + пароль. Пароль — `DEMO_PASSWORD` з `.env` сервера; **на екрані не показувати** (журі отримує його у формі здачі).
- Станції, генератори й акумулятори — **ДЕМО** (на екрані позначка «ДЕМО» / «МОК»). Кажемо це вголос один раз (00:20). Будівлі, споживання UMUNI, PVGIS, бюджет openbudget і платежі spending — реальні.
- Цифри нижче звірено з API 20.11.2026 (ціна 11,57 грн/кВт·год — факт 2025, клас «Надлишок» вимкнено). Період «День» і «Місяць» рахуються **на сьогодні**: у листопаді всі станції «Не вистачає».

**Перед записом:** два вікна браузера — одне з входом `energo`, друге (приватне) з входом `finance`. Масштаб 110–125 %, сповіщення вимкнути, тур «Як користуватися» закрити.

## Якщо мережа впала

1. **Локальна копія** (запустити заздалегідь): `cp .env.example .env`, задати `DEMO_PASSWORD`, `docker compose up --build` → http://localhost:8000. Ті самі шляхи: `/dashboard`, `/`, `/object/9795`, `/finance`, `/report`, `/blackout`. PVGIS у кеші. **Підкладка мапи (тайли OpenStreetMap) і графік відключень без мережі не завантажаться** — точки будуть, карти під ними ні; тоді починаємо з огляду громади.
2. **Відео** на ноутбуці й на флешці (MP4) — замість живого демо.
3. **Скріншоти** ключових екранів у PDF презентації — останній варіант.
