# Сценарій демо · City Insight Map · Енергія

Відео **≤ 3 хв**, на реальному прототипі, **три сценарії розділу 3 ТЗ**:
1. «Мешканець, журналіст, депутат: прозорість» (2.1, 2.2);
2. «Енергоменеджер: план-факт / ефективність СЕС» (2.2);
3. «Посадовець, що планує нові СЕС» (2.2).

Плюс 15 с на ролі (публічний режим vs внутрішній). Той самий маршрут — для живого демо на пітчі.

- Сайт: **https://pl.mindal1ka.com** (або локально http://localhost:8000).
- Вхід: ПІБ «Демо Енергоменеджер», посада «Енергоменеджер», роль «Енергоменеджер міста», пароль — `DEMO_PASSWORD` з `.env` сервера (не показувати на екрані). Справжні ПІБ не вводимо.
- Станції — **ДЕМО**. Кажемо це вголос один раз (00:30). Споживання, будівлі, PVGIS — реальні.
- Період «День» і «Місяць» рахуються **на сьогодні**: у листопаді всі станції «Не вистачає». Червень показуємо цифрою зі слайда 5, а не в інтерфейсі.

**Перед записом:** відкрити дві вікна: **приватне без входу** (публічний режим) і **звичайне з входом** енергоменеджера. Масштаб браузера 110–125 %, сповіщення вимкнути, тур «Як користуватися» закрити.

## Якщо мережа впала

1. **Локальна копія** (запустити заздалегідь): `docker compose up --build` у корені репозиторію → http://localhost:8000. Ті самі шляхи: `/`, `/dashboard`, `/dashboard?p=month`, `/object/9609`, `/object/9595`, `/solar?budget=5`, `/defects`. PVGIS у кеші, мережа не потрібна. **Підкладка мапи (тайли OpenStreetMap) без мережі не завантажиться** — точки будуть, карти під ними ні; тоді починаємо з дашборду.
2. **Відео** на ноутбуці й на флешці (MP4) — замість живого демо.
3. **Скріншоти** ключових екранів у PDF слайдів — останній варіант.
