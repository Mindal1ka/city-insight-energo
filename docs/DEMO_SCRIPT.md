# Сценарій демо · City Insight Map · Енергія

Відео **≤ 3 хв**, щонайменше 2 сценарії треку. Цей самий маршрут — для живого демо на пітчі.

- Сайт: **https://pl.mindal1ka.com**
- Вхід **тестовий**: будь-яке ПІБ із двох слів (наприклад, «Демо Енергоменеджер») і будь-який пароль. Справжні ПІБ не вводимо.
- Перемикач **«Зараз / Літній день»** вгорі сторінок: «Літній день» = **05.06.2026, 13:00** (`?view=summer`). Узимку станції в дефіциті, влітку видно надлишок.
- Усе, що позначено **«ДЕМО»**, — змодельовані станції й телеметрія. Кажемо це вголос один раз (00:20).

**Перед записом:** увійти заздалегідь (вхід живе у вкладці), відкрити вкладки 1–5 нижче, масштаб браузера 110–125 %, сповіщення вимкнути.

## Якщо мережа впала

1. **Локальна копія** (запустити заздалегідь, до 14:00): `docker compose up --build` у корені репозиторію → http://localhost:8000. Ті самі шляхи: `/`, `/object/9623?tab=distribution&view=summer`, `/independence`, `/solar`, `/solar/9602`, `/defects`. PVGIS у кеші, тож мережа не потрібна. Прогноз Open-Meteo без мережі показує середнє PVGIS з позначкою.
2. **Відео** на ноутбуці й на флешці (MP4) — запустити замість живого демо.
3. **Скріншоти** ключових екранів у PDF слайдів (слайд 8) — останній варіант.
